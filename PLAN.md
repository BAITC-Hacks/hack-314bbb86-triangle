# План реализации: «Аким на 5 часов»

Цель: воспроизводимый симулятор команды Triangle для трека Astana Innovations.
Работа выполняется последовательно в текущей сессии по поручению пользователя.

## Архитектура и принятые решения

Node.js 22+, ES modules, HTML/CSS/SVG, без внешних зависимостей.
`public/data.mjs` — исходные данные; `public/engine.mjs` — чистые функции
валидации и расчёта, общие для сервера и интерфейса. `server.mjs` повторно
проверяет каждый сценарий; `advisor.mjs` передаёт вычисленные факты в OpenAI.
Ключ хранится только в окружении сервера. Без ключа доступен явно обозначенный
локальный аналитический отчёт, не выдаваемый за LLM.

Подробный датасет принят как спецификация: 100 единиц, ровно 5 разных мер,
максимум 2 из одного направления, район обязателен только для районных мер,
горизонт 8 кварталов, лаги, три синергии и три несовместимости.
Это отличается от возможного прочтения общего брифа «по одной мере из каждого
направления». Все пять направлений доступны, но охват каждого не обязателен.
Числа из примеров проверяются по формуле, а не подгоняются к округлённым ответам.

Дизайн: городская диспетчерская. Светлый фон #f4f7fa, тёмно-синяя навигация
#142c42, морской акцент #087e8b, речной голубой #b9e1ed, оранжевый #cb7133,
белые поверхности. Шрифт Segoe UI с системными fallback. Главный элемент —
интерактивная схема пяти районов с рекой и исходными/новыми значениями;
это условная схема, а не географическая карта. Каталог и панель бюджета
на одном экране. Мобильная версия, клавиатурная навигация и видимый фокус.

## Условия приёмки

Все пользователи получают одну версию данных и 100 единиц. Невалидный набор
не получает итоговый Score. Изменение допустимого набора меняет показатели.
Объяснение содержит сильные стороны, риски, компромиссы и вычисленное улучшение.
Никакие секреты не попадают в браузер или репозиторий.

## Риски для проверки

1. Отсутствие/ошибка AI API: расчёт сохраняется, режим отчёта обозначен.
2. Некорректный JSON или объекты вместо ID: ответ 400, сервер продолжает работу.
3. Устаревший AI-ответ после изменения решений: UI не показывает старый отчёт.
4. Данные localStorage повреждены: приложение загружается с пустым списком.
5. Чужой коммит во время публикации: обновление ветки без force, конфликт не затирается.
