# AKIM — Astana City Lab

**«Аким на 5 часов» / «5 сағатқа әкім» / Mayor for 5 Hours**  
Triangle · Astana Innovations · Hackathon track 12

Интерактивный симулятор городского управления: реальные границы районов Астаны,
100 единиц бюджета, пять решений и объяснимый **Astana Quality of Life Score**.
Интерфейс, каталог инициатив и AI-отчёты доступны на **қазақша / русском / English**.

Сайт: [Открыть AKIM City Lab](https://akim-triangle-city-lab.dimash-islam61.chatgpt.site)

## Быстрый запуск

Требуется Node.js **22.12+** и npm. Команды из корня репозитория:

```bash
npm ci
cp .env.example .env
npm run dev
```

Windows PowerShell: `Copy-Item .env.example .env`. Откройте **http://127.0.0.1:3100**.
Заполните `OPENAI_API_KEY` в `.env` для реального AI. Без ключа доступно честно
помеченное объяснение по правилам; расчёт и сохранение продолжают работать.
Ключ считывается только сервером. `.env`, SQLite-файлы и сборки исключены из Git.

```bash
npm test                 # 22 проверки модели, API, доступа и SQLite
npm run build           # React + Worker + миграции базы
npm start               # локально обслуживать готовую сборку на :3100
npm run db:generate     # после изменения db/schema.ts
```

`node:sqlite` в Node 22.12 выводит предупреждение experimental — это ожидаемо.
Локальный сервер слушает только loopback. Для размещения используется Sites
с Worker и D1; это отдельный адаптер того же API, не раздача локального компьютера.

## Демонстрация за 3 минуты

1. На главной выберите язык. Откройте **Карту** и сравните районы.
2. Выберите Нұра и нажмите «Инвестировать в этот район».
3. В **Решениях** выберите пять мероприятий или нажмите «Загрузить пример».
4. Нажмите «Посмотреть результат»: пример тратит **95**, Score **56.54307**
   (на экране **56.54**), улучшение **3.98539**. AI объясняет сильные стороны,
   риски и компромиссы; расчёт не зависит от ответа модели.
5. Примените проверенную альтернативу M5 → M3 в Нұре: стоимость **100**,
   Score **57.20556**. Сохраните оба варианта и сравните в **Сценариях**.
6. Создайте ссылку для чтения. Отдельной кнопкой можно опубликовать результат
   в общем рейтинге. JSON и печатный отчёт доступны на странице результата.

## Что реализовано

- Отдельные страницы: главная, карта, симулятор, мои сценарии, результат,
  общая ссылка, сравнение 2–3 сценариев, рейтинг и методика.
- Реальная 2D-карта Leaflet: масштабирование, выбор района, границы OSM,
  показатели до/после. При недоступных тайлах остаются локальные границы.
- Полный набор организаторов: **5 районов, 10 показателей, 14 мероприятий**.
- Единый бюджет, запрет превышения и несовместимостей на фронтенде **и сервере**.
- AI через OpenAI Responses API; локализованный отчёт, кеш, лимиты и fallback.
- SQLite локально, D1 при размещении; миграции Drizzle в репозитории.
- Владение сценариями проверяется сервером. Чужие личные сценарии не доступны.
- Адаптивный интерфейс, клавиатурная навигация, диалоги, состояния ожидания,
  ошибок и пустых списков. Черновик переживает обновление страницы.

## Точная модель организаторов

Использованы подробные правила приложенного датасета: **ровно 5 разных мер**,
**не более 2 из одного направления**. Не требуется по одной мере на каждое
направление — это существенная деталь подробного ТЗ. Все пять направлений доступны.

1. Начальный бюджет — **100**; неиспользованный остаток не даёт бонус.
2. Горизонт — **8 кварталов**. Реализованный эффект:
   `полный эффект × (8 − лаг) / 8`.
3. Городские меры влияют на все пять районов; локальным нужен район.
4. `M1 + M3` несовместимы в любом сочетании районов.
   `M4 + M7` и `M5 + M13` несовместимы только в одном районе.
5. Синергии `M1+M2`, `M5+M6`, `M10+M12` применяются в районе локальной меры
   и не уменьшаются лагом. Показатели ограничены диапазоном 0–100.
6. Балл района = сумма десяти показателей, умноженных на их веса.
7. `AVG` — среднее районов с учётом долей населения; `MIN` — слабейший район.
8. `K` — число показателей **строго ниже 40** во всех районах.

```text
Astana Quality of Life Score = 0.7 × AVG + 0.3 × MIN − K
Базовый Score              = 52.55768
AVG                        = 56.8624
MIN                        = 49.18 (Нұра)
K                          = 2
```

Веса, исходные значения, эффекты, лаги и синергии открыты в `shared/data.mjs`
и на странице «Методика». Все 50 исходных показателей одинаковы для игроков.
Рекомендации перебирают **одну замену** и возвращают до трёх лучших допустимых
улучшений; это не обещание глобального оптимума. Вклады мер рассчитываются
методом исключения одной меры и **не складываются** из-за порогов и синергий.

## География и источник данных

На карте шесть текущих районов OpenStreetMap; учебный датасет содержит пять.
Сарайшық показан нейтральным и исключён из расчёта, без выдуманных показателей.
Границы OSM не являются официальной кадастровой картой, а учебные показатели
не являются реальной статистикой города. Даты, relation IDs, лицензия ODbL
и ссылки: [docs/MAP-SOURCES.md](docs/MAP-SOURCES.md).

## Архитектура

```text
frontend/              React 19, React Router, Leaflet, CSS, 3 языка
  public/              GeoJSON шести районов и favicon
  src/                 страницы, карта, результаты, переводы, API-клиент
backend/
  api.mjs              серверная валидация, сценарии, ссылки, рейтинг, AI
  advisor.mjs          OpenAI Responses и объяснение по правилам
  database.mjs         параметризованные запросы и атомарные квоты
  sqlite.mjs           SQLite и применение миграций локально
  local.mjs            Node HTTP + Vite / production assets
  worker.mjs           Cloudflare Worker + Sites identity + assets
shared/                синтетические данные, модель, переводы каталога
db/schema.ts           схема Drizzle
drizzle/               сгенерированные SQL-миграции и метаданные
tests/                 node:test, изолированные базы, без платных API-вызовов
scripts/build.mjs      единая сборка клиента, сервера и миграций
.openai/hosting.json   идентификатор сайта и логическая привязка D1
```

Клиент и сервер используют одну модель. Предварительный расчёт выполняется в
браузере, итоговый повторяется сервером. Клиентский `score` не принимается.
База хранит решения, версию датасета и вычисленный результат для рейтинга;
при чтении показатели пересчитываются из решений.

### API

| Метод | Путь | Доступ / назначение |
| --- | --- | --- |
| GET | `/api/config` | Публично: правила, наличие AI, текущая сессия |
| POST | `/api/simulate` | Публично: `{decisions}` → проверенный результат |
| POST | `/api/analyze` | `{decisions,locale}` → результат, отчёт, альтернативы |
| GET / POST | `/api/scenarios` | Свои сценарии / сохранить `{name,team,decisions}` |
| GET / DELETE | `/api/scenarios/:id` | Только владелец |
| POST | `/api/scenarios/:id/share` | Владелец создаёт ссылку только для чтения |
| POST | `/api/scenarios/:id/publish` | Владелец явно публикует в рейтинг |
| GET | `/api/shared/:token` | Публичное чтение по непрогнозируемому UUID |
| GET | `/api/leaderboard` | Публичные результаты текущей версии модели |

### Доступ и хранение

- Облачный сайт открыт всем по ссылке. Для своих сохранений и платного AI
  нужен вход через ChatGPT; гостю доступны карта, расчёт и объяснение по правилам.
- Worker доверяет заголовкам `oai-authenticated-user-*` **только за доверенным
  шлюзом Sites**. Для самостоятельного размещения Worker нужен свой auth middleware.
- В локальном режиме отдельный HttpOnly/SameSite cookie создаёт учебную сессию;
  это не полноценная система аккаунтов. База хранится в `.data/akim.sqlite`.
- LocalStorage содержит только язык и черновик, не является базой сценариев.
- До 100 сценариев на владельца. Лимит вставки атомарный, SQL параметризован.
- Публикация в рейтинге раскрывает название команды, сценарий и решения.
  Удаление сценария удаляет его из рейтинга и делает общую ссылку недоступной.

### AI

`OPENAI_MODEL=gpt-4.1-mini`; сервер передаёт только синтетические показатели и
решения, без имён пользователей и команд. Ключ не попадает в клиент и Git.
`store:false`, JSON Schema, таймаут 25 секунд. Кеш привязан к решениям, языку,
версии модели расчёта, версии промпта и имени AI-модели. До 3 новых запросов
в минуту на игрока, общий лимит по умолчанию 60/день (`AI_DAILY_LIMIT`).
При отсутствии ключа, превышении лимита или ошибке AI результат остаётся
доступным с объяснением по правилам и явной отметкой режима.
AI может неточно сформулировать вывод: численные карточки и проверенные
альтернативы всегда берутся из детерминированного движка.

## Работа команды из трёх человек

```bash
git clone https://github.com/BAITC-Hacks/hack-314bbb86-triangle.git
cd hack-314bbb86-triangle
git switch -c feature/your-task
npm ci
```

Разделение: участник 1 — `frontend/`; участник 2 — `backend/`, `db/`, `drizzle/`;
участник 3 — модель `shared/`, тесты, документация и презентация. Общие
контракты API и формулу обсуждать перед изменениями. Обычный процесс: commit →
push ветки → pull request → review → merge. Запись файла на компьютере сама
по себе не отправляет его в GitHub. Секреты каждому участнику передаются отдельно.

## Проверка и развитие

`npm test`: 22 автоматические проверки. Покрыты исходная формула, пример,
100/103 единицы, 4/5/6 решений, дубль, неизвестные поля, все конфликты,
лаги, синергии, отрицательные эффекты, порог 40, рекомендации, владельцы,
ссылки/рейтинг, гонки запросов, сохранение после перезапуска SQLite,
AI-кеш по языкам и ограничения запросов. Реальный AI дополнительно проверяется
вручную, чтобы обычные тесты не тратили ключ команды.

Следующие осмысленные улучшения: совместная командная сессия с ролями;
неожиданные события в отдельном режиме с фиксированным seed; реальные данные
только с подтверждёнными источниками и новой версией модели; 3D-экструзии
карты; экспорт презентации. Они не меняют честные стартовые условия текущего режима.

## Қазақша

`.env` ретінде сақтаңыз, `npm run dev`, кейін `http://127.0.0.1:3100` ашыңыз.

## English

Explore real Astana district geometry, invest 100 units in exactly five
distinct measures, and receive an explainable Quality of Life Score.
The deterministic model controls every number; AI explains trade-offs.
React frontend, Node/Worker backend, persistent SQLite/D1 database,
three languages, saved scenarios, comparisons, read-only sharing and opt-in
leaderboard. Data are synthetic, not current city statistics. Run `npm ci`,
copy `.env.example` to `.env`, then `npm run dev`. Tests: `npm test`.

The hosted site is public. Saving and live AI require ChatGPT sign-in;
maps, scoring and rule-based explanations remain available to guests.
