# Проверка версии 2 — 23 сентября 2026

## Автоматические проверки

`npm test` — **22 теста**, Node.js 22.12, SQLite in-memory и временный файл.
Наборы: `tests/engine.test.mjs`, `tests/api.test.mjs`.

- Точные исходные показатели, веса, население и baseline 52.55768.
- Пример организаторов: стоимость 95, Score 56.54307, два критических
  показателя устранены; лучшая одиночная замена даёт 57.20556 при бюджете 100.
- Число решений, дубли, бюджет, области действия, три несовместимости,
  синергии, лаг, порог строго ниже 40, отрицательные эффекты и clipping.
- Создание/чтение/удаление сценариев; изоляция владельцев, гостевой доступ,
  общий токен, явная публикация и рейтинг — в изолированной базе.
- Параллельное создание не превышает 100 записей; параллельное создание
  ссылки не отменяет публикацию. Сохранение после закрытия/открытия SQLite.
- Ошибочные JSON, тип содержимого, размер запроса, проверка Origin.
- AI-кеш по языку, предел запросов, fallback без ключа без расхода квоты.
- AI получает реализованные эффекты (M7: +10, не полный +16), названия метрик;
  численный заголовок отчёта формируется движком, а не ответом модели.

## Браузерная проверка локального приложения

- Главная: карта, навигация, корректное переключение ҚАЗ/RU/EN.
- Карта: реальные тайлы OpenStreetMap, шесть границ; выбор Есіл меняет
  правую панель с 49.18 Нұры на 62.99 Есіл.
- Симулятор: готовый пример, расчёт 56.54, бюджет 95/100, отчёт AI.
- Сценарий сохранён через форму, после обновления страницы прочитан из базы.
- Создана ссылка для чтения; сравнение двух сохранённых сценариев отображает
  баллы, бюджет, районы и все решения.
- Мобильный viewport 390×844: главная, меню и панель решений;
  горизонтального переполнения страницы нет.
- Настоящие Responses API вызовы вернули `mode: ai` на kk, ru, en.
  После уточнения фактов отдельно проверен английский отчёт с эффектами после лага.

Браузерное подтверждение публикации тестового сценария не выполнено:
автоматический контроль разрешений запретил финальное нажатие. Диалог отменён.
Серверная публикация/рейтинг проверены автоматическими тестами в изолированной базе;
тестовые записи не были отправлены в публичный рейтинг сайта.

## Сборка и размещение

Vite создаёт клиент, esbuild — Worker; SQL-миграции включены в артефакт.
Первое облачное размещение подтверждено статусом `succeeded` и ревизией
переменных окружения 1. Доступ сайта — public, ключ хранится как secret.

Код и актуальный README опубликованы в репозитории команды.
Облачный интерфейс не проходил отдельный ручной браузерный прогон:
функциональная проверка выполнена локально, размещение проверено по статусу сервиса.
