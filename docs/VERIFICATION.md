## Браузерная проверка локального приложения

- Главная: карта, навигация, корректное переключение ҚАЗ/RU/EN.
- Карта: реальные тайлы OpenStreetMap, шесть границ; выбор Есіл меняет
  правую панель с 49.18 Нұры на 62.99 Есіл.
- Симулятор: готовый пример, расчёт 56.54, бюджет 95/100, отчёт AI.
- Сценарий сохранён через форму, после обновления страницы прочитан из базы.
- Создана ссылка для чтения; сравнение двух сохранённых сценариев отображает
  баллы, бюджет, районы и все решения.
- Мобильный viewport 390×844: главная, меню и панель решений;
  горизонтального переполнения страницы нет.
- Настоящие Responses API вызовы вернули `mode: ai` на kk, ru, en.
  После уточнения фактов отдельно проверен английский отчёт с эффектами после лага.

Браузерное подтверждение публикации тестового сценария не выполнено:
автоматический контроль разрешений запретил финальное нажатие. Диалог отменён.

тестовые записи не были отправлены в публичный рейтинг сайта.
